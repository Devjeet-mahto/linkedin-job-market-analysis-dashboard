# linkedin-job-market-analysis-dashboard
Interactive Power BI dashboard analyzing LinkedIn job market trends, skill demand, salary distribution, hiring locations, and job-level insights.

Project Overview

This project analyzes LinkedIn job market data using Power BI to uncover insights about hiring trends, salary distribution, skill demand, company participation, and geographic job opportunities.

Tools Used
Power BI
Excel
Power Query
DAX
Key Insights
Analyzed 850+ job postings.
IT skills emerged as the most demanded skill category.
40% of openings belong to Mid-Senior level positions.
Most jobs fall within the $0–50K salary range.
California, New York, and Texas lead hiring activity.
Dashboard Features
KPI Cards
Salary Analysis
Skills Demand Analysis
Hiring Trend Analysis
Geographic Job Distribution
Job Type Analysis
Business Impact

This dashboard helps job seekers identify high-demand skills, target hiring locations, and understand salary trends for better career planning.
